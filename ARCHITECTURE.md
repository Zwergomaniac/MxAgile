# Architecture

## Canonical MxAgile Architecture

- **Lifecycle:** Discovery → Refinement → Ready → Implementing → Verifying.
- **Traceability:** Wave-reports and process state tracking in `.concord/scratch/process-state.yaml`.
- **Core/Layer Separation:** Project-specific overrides vs. company-layer merges.
- **Source of Truth:** Canonical MDL-based Mendix model.
