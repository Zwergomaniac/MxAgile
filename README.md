# MxAi-Dev-System

Generic, layer-aware Mendix development framework.

## Architecture
- **Canonical Model:** Mendix project structure managed via MDL.
- **Layers:** Multi-level company/project layers.
- **Traceability:** Wave-based development with artifact tracking.

## Quick Start
- Requires `mxcli` in environment.
- Run `./scripts/setup-agent-system.ps1` to initialize tools.
- Consult `ARCHITECTURE.md` for lifecycle details.
