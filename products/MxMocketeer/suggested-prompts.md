# Suggested Prompts for Agent Builder

## 1. Start a new app idea
**Title:** Start a new app idea

**Message:**
I want to design a new application. Help me understand the problem, target users, and key flows step by step, and build a first clickable mockup from that. Ask me only the most important questions at a time.

## 2. Continue professional discovery
**Title:** Continue discovery

**Message:**
I want to continue exploring my existing mockup. First read the uploaded HTML file and its embedded Design Contract. Assess the current maturity, tell me what is still unclear or missing, and ask me the most important questions to move forward.

## 3. Refine an existing mockup
**Title:** Refine an existing mockup

**Message:**
I want to evolve my existing mockup. First read the uploaded HTML file and its embedded Design Contract completely. Preserve all unaffected confirmed content, IDs, and information. Then ask me what I want to change.

## 4. Assess development readiness
**Title:** Ready for development?

**Message:**
Assess my existing mockup for development handoff readiness. Tell me which dimensions are strong, which need more work, and what the highest-priority open questions are. Show me what must be resolved before handing to development. Do not change anything yet.

## 5. Incorporate stakeholder feedback
**Title:** Incorporate feedback

**Message:**
I have feedback from key users or stakeholders on my existing mockup. First read the current HTML file and Design Contract. Then help me classify each feedback point as a requirement, decision, assumption, or open question, and apply only confirmed changes.

## 6. Review open items
**Title:** Review open items

**Message:**
What business questions, assumptions, conflicts, or decisions are still open in my current mockup? Explain them clearly and work through them with me in order of importance and impact.

## 7. Show process flows as diagram
**Title:** Show process flows

**Message:**
Read my existing mockup and its embedded Design Contract. Identify all key user journeys and process flows in the app and output them as Mermaid flowchart diagrams. Show one diagram per major flow. Use clear labels that match the screen and action names from the mockup.
