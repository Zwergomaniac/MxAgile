# Implementation Waves

Dieses Dokument ordnet technische Arbeit innerhalb offizieller Mendix-Board-Sprints.
Es ist kein zweiter Sprintplan; Board-Sprint, Prioritaet und Status bleiben verbindlich.

## Verwendung

- Jede Wave referenziert ausschliesslich Board-Story-IDs.
- Technische Teilaufgaben, Testfaelle und Spezifikationen duerfen hier ergaenzt werden.
- Neue fachliche Anforderungen werden als Vorschlag fuer das Board markiert.
- Nach jedem Board-Sync Wave, Reconciliation-Bericht und Board-Aktionsbericht pruefen.
