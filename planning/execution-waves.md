# Implementation Waves

Dieses Dokument ordnet technische Arbeit innerhalb des MxAgile-Lifecycle.
Waves sind MxAgile-Konstrukte — sie existieren unabhaengig von einem externen Board.

Wenn ein Mendix Epics Board konfiguriert ist, koennen Waves Board-Story-IDs fuer
organisatorische Traceability referenzieren. Board-Existenz autorisiert keinen Scope.

## Verwendung

- Jede Wave referenziert MxAgile-autorisierte Requirement-IDs (und optional Board-Story-IDs).
- Technische Teilaufgaben, Testfaelle und Spezifikationen duerfen hier ergaenzt werden.
- Neue fachliche Anforderungen werden als Vorschlag markiert und benoetigen Entwicklerfreigabe.
- Nach jedem Board-Sync (wenn Board konfiguriert): Wave, Reconciliation-Bericht und
  Board-Aktionsbericht pruefen. Board-Sync importiert keinen neuen Scope.
